# Taskly Pro 2.4.0 — AI Productivity Assistant

## AI capabilities
- Local Taskly AI chat using the existing workspace data.
- Quick prompts for daily planning, overdue tasks, note analysis and prioritization.
- Natural-language task creation, for example: `Create task: submit assignment tomorrow`.
- AI-created tasks are saved through the same encrypted workspace storage used by Taskly Pro 2.3.
- AI context loading understands `ENC1:` encrypted task/note payloads.
- No external AI API key is required for these local assistant features.

## Security compatibility
- Keeps Taskly Pro 2.3 App Lock, biometric authentication and encrypted local data.
- Updated `flutter_secure_storage` to 11.2.0 and `local_auth` to 3.0.2.
