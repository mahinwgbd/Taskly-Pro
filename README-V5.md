# Taskly V5

Taskly V5 is a practical upgrade of the V4 workspace with a real task-planning flow, calendar, editing, priorities and a cleaner profile layout.

## V5 features
- Profile form is fully vertical to prevent small-screen RenderFlex overflow.
- Profile hero shows name, designation/profession, workplace and blood group cleanly.
- Expanded local profile remains persistent.
- Tasks are user-created; no demo/default tasks are injected.
- Task creation supports title, description, category, priority, date, time, repeat and reminder.
- Existing tasks can be edited by tapping a task.
- Tasks can be completed/uncompleted and deleted by swipe.
- Task search, category filters and hide-completed filter.
- Calendar tab with date selection and tasks for the selected day.
- Home shows today's progress and today's tasks.
- Quick Notes keeps a visible Add note action.
- Notes and tasks persist locally with SharedPreferences.
- Project cards show live task counts and open the corresponding task filter.
- Light/Dark/System appearance and notification preferences retained.
- Kotlin incremental compilation disabled to avoid the Windows C:/D: Pub Cache path-root issue.
