# Taskly Pro 1.2.0 — Advanced Notes & Knowledge Base

Adds a Pro Notes/Knowledge Base hub on top of the existing NoteItem model.

- Full-text title/content/tag search
- Tag filtering
- Recent/title sorting
- Dark/light note previews using the existing note palette
- Knowledge Base hub from Settings > Taskly Pro
- Existing notes remain storage-compatible; no destructive migration

Version: 1.2.0+2
