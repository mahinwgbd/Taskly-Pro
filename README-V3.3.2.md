# Taskly V3.3.2 — Final Polish

Final polish release for Taskly.

## Final updates
- Stable Bangla / English UI switching with the selected language highlight updating immediately.
- Bangla UI numbers use Bengali digits where generated by Taskly.
- New users start as Explorer with a neutral guest avatar until a profile photo is selected.
- Developer identity is prominently available in Settings.
- Existing tasks, notes, profile content, Google Drive sync, reminders, recurring tasks, focus, calendar and insights are preserved.
- Release build remains ABI-split and R8 optimized for smaller APKs.

## Build
```powershell
flutter clean
flutter pub get
flutter build apk --release
```
