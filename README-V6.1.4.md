# Taskly V6.1.4

## What changed

### Home redesign
- New dynamic hero dashboard
- Animated ambient header motion
- Cleaner task progress presentation
- Done / Left / Notes quick stats
- More intentional empty states for new users
- Redesigned Today, Quick Notes and Focus Spaces sections
- Better note previews on Home
- More compact and readable task cards

### First launch experience
- Animated Taskly splash
- Three-step onboarding
- Skip option
- Onboarding is shown only on first launch
- Returning users go directly to Home

### New-user workspace
- Tasks start empty
- Notes start empty
- No bundled demo/sample tasks or notes are created by the application
- Existing saved data is preserved during normal upgrades

## Run

```powershell
flutter pub get
flutter analyze
flutter run -d emulator-5554 --dart-define=TASKLY_GOOGLE_SERVER_CLIENT_ID=YOUR_WEB_CLIENT_ID.apps.googleusercontent.com
```
