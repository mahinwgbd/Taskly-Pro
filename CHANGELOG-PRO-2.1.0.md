# Taskly Pro 2.1.0

- Added Pro Workflow hub with project templates.
- Added local-first Taskly AI chat foundation.
- AI assistant can analyze tasks/notes locally and suggest next actions.
- Added Pro 2.1 and Taskly AI entry points from Taskly Pro.
- Preserved existing Pro 2.0 workspace compatibility.

## AI architecture
The first release is local-first and does not require an API key. A production cloud AI provider should be connected through a secure backend rather than embedding a provider secret in the APK.
