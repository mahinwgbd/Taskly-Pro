# Taskly V6

Taskly V6 is based directly on the supplied TasklyV5 project.

## V6 Core additions
- Smart Insights screen
- Completion, pending, overdue and high-priority statistics
- Today metrics
- Weekly productivity bars
- Category completion analytics
- Four-tab navigation: Home, Tasks, Calendar, Insights
- V5 task/note data migration: V6 loads existing V5 SharedPreferences keys when V6 keys are not present
- Version 6.0.0+6

## Run
Extract this project, then:

    flutter clean
    flutter pub get
    flutter analyze
    flutter run -d emulator-5554

The project is intended for the user's existing Flutter/Android setup.
