# Taskly V3.5.0

Core productivity upgrade batch.

## Included
- Notes: Active / Archived / Trash views
- Notes: archive, restore and permanent delete actions
- Notes: move-to-trash with Undo snackbar
- Tasks: delete with Undo snackbar
- Tasks: completion with Undo snackbar
- Task checkbox: larger accessible hit target and animated state
- Existing dark-mode and keyboard fixes preserved
- Version bumped to 3.5.0+35

## Build
`flutter clean`
`flutter pub get`
`flutter build apk --release --split-per-abi`
