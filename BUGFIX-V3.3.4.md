# Taskly V3.3.4

## Bug fixes

- Fixed Quick Notes / Notes cards using light pastel backgrounds in dark mode, which made note content hard to read. Dark-mode note cards now use dedicated dark palettes with readable foreground text.
- Fixed task checkbox confusion on the Home screen by keeping task positions stable after completion instead of immediately reordering completed tasks below pending tasks.
- Preserved existing keyboard auto-scroll and draggable note-editor fixes from V3.3.3.
