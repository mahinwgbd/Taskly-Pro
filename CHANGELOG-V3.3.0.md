# Taskly V3.3.0

## Localization
- Added app-wide Bangla/English switching from the Home header.
- Language choice is persisted in SharedPreferences.
- Material/Cupertino/Widgets locale is updated together with Taskly's own UI strings.
- Tasks, Notes, Calendar, Insights, Focus, Settings, profile, dialogs, search and Google Drive UI use the selected language where applicable.
- User-created task titles, note content, profile values and tags are never translated.

## Polish
- Existing dark-mode input readability improvements retained.
- Existing note editor/color fixes retained.
- Version bumped to 3.3.0+26.
